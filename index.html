How attendance is calculated
  • Full Day Present — 1.0 working day, 1.0 attended.
  • Half Day Present — 0.5 working day, 0.5 attended.
  • Medical Leave (Full/Half) — credited as Present by school's policy. Counts toward Official % but shown separately. Actual % excludes it.
  • Absent (Full/Half) — counts as working day, 0 attended.
  • Holiday — completely excluded from working days and attendance %.
  • Sunday / 2nd Saturday — automatic non-working days. Excluded from all calculations.
Official % (Present×dur + Medical×dur) ÷ Working Days × 100
Actual % (Present×dur) ÷ Working Days × 100
Working Days Σ dur for all non-holiday records (full=1, half=0.5)

The school's 75% requirement uses Official Attendance. That is what the progress ring and Smart Leave Predictor display.
